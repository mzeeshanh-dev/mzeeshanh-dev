<h2 align="center">About</h2>

<p align="center">
Software engineer with 2+ years of experience. I started on the MERN stack and now focus on <b>LLM-powered backends</b>:<br />
agent loops, tool calling, multi-step agent workflows, retrieval-augmented generation and LLM inference, built mainly in Node.js and TypeScript.<br />
Previously at Earth Scan Systems (2024 to 2026), building GIS and agritech decision-support products with NestJS, PostgreSQL and a RAG assistant.
